## Chrome 应用商店

- [ ] 商店描述里说明：选中的文本会发送给用户选择的翻译服务
- [ ] 单一用途说明：在网页上翻译用户选中的文本
- [ ] 权限理由：
  - `<all_urls>` 内容脚本：在任意网页显示划词按钮和翻译卡片
  - `storage`：保存设置、API Key 和翻译缓存
  - `contextMenus`：右键菜单入口
  - 各 host 权限：调用对应的翻译接口
  - 可选 host 权限：用户自定义的 OpenAI 兼容接口，按域名单独授权
- [ ] 数据使用声明：处理“网站内容”（用户选中的文本），仅用于提供翻译功能，不出售、不用于其他用途
- [ ] 隐私政策链接指向 `PRIVACY.md`（或单独托管的页面）
- [ ] 确认没有远程代码、没有 `eval`：`grep -rn "eval(\|new Function" .output/chrome-mv3` 应当为空
- [ ] 截图：1280×800 或 640×400，至少 1 张
- [ ] 图标：128×128
